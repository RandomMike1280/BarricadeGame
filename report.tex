\begin{abstract}
This technical report describes Wium, a system trained to play Quoridor from scratch with no prior human knowledge. AlphaZero-style self-play reinforcement learning had proven success for many board games, and I continue to apply it to the game Quoridor. Here, I describes a set of techniques I applied to improve the training process and the final performance of the model
\end{abstract}
